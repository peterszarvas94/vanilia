TypeScript

Types ship next to the module as vanilia-editor.d.ts. Keep it beside vanilia-editor.js and a relative import is typed with no setup. When you import the bare "vanilia-editor" through an import map, tell TypeScript where the types are, because it doesn't read import maps:

{{template "code" `// tsconfig.json { "compilerOptions": { "paths": { "vanilia-editor": ["./static/vendor/vanilia-editor.d.ts"] } } }`}}

Importing the module also types the element and its events, so there is nothing to cast. Commands and icon names are checked too:

{{template "code" `import "vanilia-editor"; const editor = document.querySelector("vanilia-editor"); // VaniliaEditorElement | null editor?.addEventListener("editorupdate", (event) => { console.log(event.detail.words, event.detail.active.bold); }); editor?.exec("bold"); // "bolt" would be a type error`}}

Exported types include VaniliaEditorDetail, EditorCommand, IconName and UploadHandler.

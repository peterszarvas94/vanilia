Attributes

Everything you can configure in HTML, without JavaScript.

Attributes

AttributeDescription
nameForm field name.
valueInitial HTML (alternative to a child <template>).
placeholderText shown while the editor is empty. Overrides the placeholder label.
requiredFails form validation when the editor has no text or image.
disabledMakes the editor read-only and excludes it from submission.
upload-urlEndpoint that receives image uploads. See Image uploads.
toolbarToolbar layout: button names with | between groups ("bold italic | h2 h3 | link"), or "none" to hide it. Without it the full default toolbar is shown. See Toolbar.
bubble-menuLayout of the menu shown over selected text, same syntax. "none" turns it off.
shortcuts"none" turns off every keyboard shortcut, built-in and custom. See Keyboard shortcuts.
theme"light" or "dark" pins the color scheme; "auto" (or no attribute) follows the page's color-scheme.

Child templates

Child <template> elements carry content and configuration. They're read once, when the editor starts.

ChildDescription
<template>Initial content.
<template data-ve-icon="bold">Replaces one icon. See Icons.
<template data-ve-labels>Label overrides as JSON. See Labels & translation.
<template data-ve-shortcuts>Shortcut overrides as JSON. See Keyboard shortcuts.

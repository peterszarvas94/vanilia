Labels & translation

Every piece of text the editor shows has a name: button tooltips, popovers, find & replace, the word count, status and validation messages. Override any of them for one editor or for the whole page. Names you leave out keep the English default.

In HTML

A <template data-ve-labels> child holds overrides as JSON:

{{template "code" ` `}}

From JavaScript

{{template "code" `import { setLabels } from "vanilia-editor"; // every editor on the page (mounted editors update too) setLabels({ bold: "Fett", italic: "Kursiv" }); // one editor; null restores a default editor.setLabels({ placeholder: "Antwort schreiben...", bold: null });`}}

Lookup order: the editor's own labels, then setLabels(), then English. The placeholder attribute wins over the placeholder label.

Placeholders and plurals

Some labels contain values in braces, like {count}. A label can also be a function that gets those values, for plural rules and grammar a template string can't express:

{{template "code" `const plural = new Intl.PluralRules("pl"); const forms = { one: "słowo", few: "słowa", many: "słów", other: "słowa" }; editor.setLabels({ wordCount: ({ count }) => count + " " + forms[plural.select(count)], imageCount: "{count} obr.", });`}}

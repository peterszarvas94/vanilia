Keyboard shortcuts

Every shortcut maps a key combination to a command or a custom button. Change, add or remove any of them for one editor or for the whole page. Button tooltips and aria-keyshortcuts follow the shortcuts in effect.

{{template "code" `import { setShortcuts } from "vanilia-editor"; // every editor on the page (mounted editors update too) setShortcuts({ bold: "Mod+Shift+B", find: false }); // one editor editor.setShortcuts({ h2: "Mod+Alt+2", // add one to a command that has none underline: false, // remove bold: null, // back to the default (or to the global setting) signature: "Mod+Alt+1", // a custom button }); editor.getShortcuts(); // { bold: ["Mod+B"], h2: ["Mod+Alt+2"], ... }`}}
ValueMeaning
"Mod+Shift+B"Replace the command's shortcuts with this one.
["Mod+Shift+Z", "Mod+Y"]Several shortcuts for one command.
false, "" or []Remove the command's shortcuts.
nullDrop the override, back to the next level.

Lookup order: the editor's overrides, then setShortcuts(), then a custom button's own shortcut, then the defaults. Any command can get a shortcut, including ones without a toolbar button (h1, paragraph, alignCenter, clearFormatting, indent, ...).

Syntax

Modifiers and a key joined with +. Modifiers: Mod, Ctrl, Meta (Cmd), Alt (Option) and Shift. The key is a letter, a digit, or any KeyboardEvent.key value such as [, Enter or F2. Letters are case-insensitive. On macOS, Option changes the character a letter key types, so combine Alt with digits or other modifiers rather than letters (Mod+Alt+2 works everywhere).

formatShortcut("Mod+Shift+X") returns the platform's display form (⇧⌘X or Ctrl+Shift+X), for showing shortcuts in your own UI.

What a removed shortcut does

Keys the browser would use to edit the content itself (Ctrl+B, I, U, Z, Y) are swallowed, so the browser doesn't apply its own formatting and the undo history stays intact. Every other removed shortcut goes back to the browser: with find: false, Ctrl+F opens the browser's find. The keydown event still bubbles out of the editor, so your page can handle a freed combination itself.

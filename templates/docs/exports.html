Module exports

Importing vanilia-editor registers the element. The named exports configure every editor on the page at once, and changes reach editors that are already mounted.

{{template "code" `import { defineButton, setIcons, setLabels, setTheme } from "vanilia-editor";`}}

Functions

ExportDescription
defineButton(button)Register a custom button for every editor. Editors with the default layout show it at the end of the toolbar; custom layouts show it where its name appears.
undefineButton(name)Remove a button registered with defineButton().
setIcons(map)Override icons; null restores one. See Icons.
setLabels(map)Override labels; null restores one. See Labels & translation.
setShortcuts(map)Assign keyboard shortcuts for every editor.
deleteShortcuts(...commands)Remove named shortcuts for every editor.
restoreDefaultShortcuts(...commands)Restore named global shortcuts, or all global overrides without names. See Keyboard shortcuts.
setTheme(tokens)Set --ve-* tokens on :root; null removes one. See Styling.
icon(name, size?, overrides?)The markup of an icon, as the editor renders it.
createTranslator(overrides?)A label lookup, (name, vars?) => string: overrides, then setLabels(), then English.
formatShortcut(shortcut)A shortcut for display on this platform: "Mod+Shift+X" is ⇧⌘X on macOS and Ctrl+Shift+X elsewhere.
tokenVar(token)The CSS property of a token: tokenVar("accentSoft") is "--ve-accent-soft".
formatHTML(html)Indent HTML for display.
isSafeUrl(url, kind)Whether a URL is allowed as a link ("link") or image source ("image").

Installation

Vanilia ships as one ES module and one stylesheet:

FileSize (gzip)What
vanilia-editor.js~44 kBThe element and its extensions, with a pinned Squire 2.4.11 (MIT) built in. Readable, not minified.
vanilia-editor.d.tsTypeScript types (optional)
vanilia-editor.css~4 kBAll styles, in cascade layers

Option A: link the hosted files

The files on this site are served with CORS headers, so you can link them directly:

{{template "code" ` `}}

Option B: copy them into your project

Download the files into your static folder (for example /static/vendor/) and use the same snippet with local paths:

{{template "code" `curl -LO https://vanilia.peterszarvas.hu/dist/vanilia-editor.js curl -LO https://vanilia.peterszarvas.hu/dist/vanilia-editor.css curl -LO https://vanilia.peterszarvas.hu/dist/vanilia-editor.d.ts # optional, for types`}}
The import map has to come before any module script that imports Vanilia. Put it once in your base layout.

Option C: with a bundler

The module has no imports of its own, so a bundler needs nothing extra: import the copied files, and keep vanilia-editor.d.ts next to the module for types.

{{template "code" `// main.ts import "./vendor/vanilia-editor.js"; import "./vendor/vanilia-editor.css"; const editor = document.querySelector("vanilia-editor"); // VaniliaEditorElement | null`}} {{end}}

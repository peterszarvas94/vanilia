Vanilia is a stylesheet plus one script, with Squire built in. Pick how you load it: a plain <script> tag, an ES module with an import map, or npm. They're the same editor.

Files

FileSize (gzip)What
vanilia-editor.css~4 kBAll styles, in cascade layers. Always needed.
vanilia-editor.iife.js~53 kBClassic script for a plain <script> tag. Registers the element and exposes the API as window.Vanilia.
vanilia-editor.js~52 kBES module, for import maps and bundlers.
vanilia-editor.d.tsTypeScript types for the ES module (optional).

Both scripts are readable, not minified, and include a pinned Squire 2.4.11 (MIT). Load one of them, not both.

Self-hosting the files

The files on this site are served with CORS headers, so you can link them directly. To serve them yourself, download them into your static folder (for example /static/vendor/) and use the snippets above with local paths:

{{template "code" `curl -LO https://vanilia.peterszarvas.hu/dist/vanilia-editor.css curl -LO https://vanilia.peterszarvas.hu/dist/vanilia-editor.iife.js # for a script tag curl -LO https://vanilia.peterszarvas.hu/dist/vanilia-editor.js # for modules curl -LO https://vanilia.peterszarvas.hu/dist/vanilia-editor.d.ts # optional, types for the module`}}

npm and bundlers

From npm

{{template "code" `npm install vanilia-editor`}} {{template "code" `import "vanilia-editor"; // registers import "vanilia-editor/vanilia-editor.css"; const editor = document.querySelector("vanilia-editor"); // typed: VaniliaEditorElement | null`}}

The package has no dependencies (Squire is bundled) and ships its types.

Copied files with a bundler

The module has no imports of its own, so a bundler needs nothing extra: import the copied files, and keep vanilia-editor.d.ts next to the module for types.

{{template "code" `// main.ts import "./vendor/vanilia-editor.js"; import "./vendor/vanilia-editor.css"; const editor = document.querySelector("vanilia-editor"); // VaniliaEditorElement | null`}} {{end}}

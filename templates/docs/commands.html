Commands

Pass these to editor.exec(). The built-in toolbar buttons have the same names, so a name that works in exec() also works in a toolbar layout (except makeLink and removeLink, which have no button).

GroupCommands
Inlinebold italic underline strike code clearFormatting
Blocksparagraph h1 h2 h3 bulletList orderedList blockquote hr
AlignmentalignLeft alignCenter alignRight (aligns the selected image when one is selected)
Linkslink (opens the link popover), makeLink + URL, removeLink
Otherimage (opens the image popover), find, undo, redo
CustomThe name of any custom button runs its run().

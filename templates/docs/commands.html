Commands

Pass these to editor.exec(). The built-in toolbar buttons have the same names, so a name that works in exec() also works in a toolbar layout, except makeLink, removeLink, subscript, superscript, indent and outdent, which have no button.

The badge shows whose code does the work: {{template "squire" .BasePath}} or {{template "vanilia" .BasePath}} (see Squire & Vanilia).

Keyboard shortcuts

Most formatting commands have a shortcut (Ctrl/⌘+B for bold, ...), and any command can get one. See Keyboard shortcuts for the defaults and how to change or remove them.

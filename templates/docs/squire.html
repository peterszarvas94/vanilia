Vanilia is a wrapper around Squire 2.4.11, the rich text engine Fastmail built for its mail editor. Squire does the editing itself; Vanilia turns it into a drop-in element and adds everything around it. Every docs page shows feature-origin badges below its title. The Commands, Keyboard shortcuts and Properties & methods pages also label individual behaviors.

{{template "squire" .BasePath}}Squire's own behavior. Vanilia calls it or exposes it unchanged, so Squire's docs describe the details.

The public API is Vanilia's either way: you call editor.exec("bold"), not Squire's bold(). The badge tells you whose code does the work. A page with only the Vanilia badge describes the custom element's API or surrounding UI rather than the underlying editing engine.

From Squire

  • The editing engine: the contenteditable surface, selection handling, typing, Enter and Backspace behavior, and pasting.
  • Inline formatting (bold, italic, underline, strike, code, subscript, superscript), lists and list levels, quotes, text alignment, links, clearing formatting.
  • The undo history.
  • Most default keyboard shortcuts (see Keyboard shortcuts), now remapped through Vanilia's shortcut map.
  • Inserting HTML, plain text and images at the cursor.
  • editor.squire: the Squire instance itself, with its full API.

Built in Vanilia

  • The <vanilia-editor> element: attributes, properties, events and form association (name, required, FormData, reset).
  • The toolbar, its layouts and custom buttons, and the selection (bubble) menu.
  • Headings and paragraphs, horizontal rules, and the link and image popovers.
  • Image upload, resize handles, width presets, image alignment and alt text. Squire's own image resizer is turned off.
  • Find & replace.
  • The paste and output sanitizer, and the clean HTML from getHTML().
  • Configurable keyboard shortcuts, plus Ctrl+K, Ctrl+F and Ctrl+Shift+X.
  • Labels and translation, icons, themes and all styles.

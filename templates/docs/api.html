MemberDescription
valueGet or set the content as HTML.
getHTML()Current content as clean HTML ("" when empty).
getFormattedHTML()Same, indented for display.
getText()Plain text content.
setHTML(html, { silent })Replace the content. silent: true skips the input event.
exec(command, arg?)Run a command.
isActive(name)Whether a format ("bold", "link", …) is active at the selection.
insertImage(url, alt?)Insert an image at the cursor.
setIcons(map)Override icons for this editor. See Icons.
onImageUploadasync (file) => url upload hook.
focus()Focus the editing surface.
form, validity, checkValidity(), reportValidity()Standard form-field members.
VaniliaEditorElement.setIcons(map)Static: override icons for every editor on the page.
VaniliaEditorElement.iconNamesStatic: names of all overridable icons.

The module also exports VaniliaEditorElement, setIcons, ICON_NAMES, formatHTML, isSafeUrl and the sanitizer helpers.

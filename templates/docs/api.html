Properties & methods

Everything on a <vanilia-editor> element. Methods called before the element is upgraded don't exist yet, so in scripts that run early wait for the definition first:

{{template "code" `await customElements.whenDefined("vanilia-editor"); const editor = document.querySelector("vanilia-editor");`}}

Everything here is Vanilia's API. Members marked {{template "squire" .BasePath}} pass straight through to Squire (see Squire & Vanilia); the rest is built in Vanilia.

Content

MemberDescription
valueGet or set the content as HTML. Writing the current value again is a no-op, so two-way bindings keep the caret.
getHTML()Current content as clean HTML ("" when empty).
getFormattedHTML()Same, indented for display.
getText()Plain text content.
getSelectedText(){{template "squire" .BasePath}} The selected text ("" when nothing is selected).
setHTML(html, { silent? })Replace the content. silent: true skips the input event.
insertHTML(html){{template "squire" .BasePath}} Insert HTML at the cursor, replacing the selection. Sanitized like pasted content.
insertText(text){{template "squire" .BasePath}} Insert plain text at the cursor, replacing the selection.
insertImage(url, alt?){{template "squire" .BasePath}} Insert an image at the cursor. Returns the <img>, or null for an unsafe URL.

Commands & state

MemberDescription
exec(command, arg?)Run a command, or the custom button of that name. arg is the URL for makeLink.
isActive(name, attrs?)Whether a format is active at the selection: "bold", "italic", "underline", "strike", "code", "link", "bulletList", "orderedList", "blockquote", "paragraph", or "heading" (optionally { level: 2 }).
focus(){{template "squire" .BasePath}} Focus the editing surface.
squire{{template "squire" .BasePath}} The underlying Squire instance, for anything the API doesn't cover. null until the element is connected. Read-only.

Toolbar & shortcuts

MemberDescription
toolbarThe toolbar layout. Reads back the items in use (an array, "|" between groups). Set a string like "bold italic | link", an array, "none", or null for the default. Reflects the toolbar attribute. See Toolbar.
bubbleMenuThe selection menu layout, same values. Reflects bubble-menu.
addButton(button)Add a custom button to this editor. An existing name is replaced.
removeButton(name)Remove a button added with addButton().
setShortcuts(map)Assign shortcuts for this editor: { bold: "Mod+Shift+B" }.
deleteShortcuts(...commands)Remove named shortcuts: editor.deleteShortcuts("underline", "find").
restoreDefaultShortcuts(...commands)Restore inherited shortcuts for named commands, or all local overrides without names. See Keyboard shortcuts.
getShortcuts()The shortcuts in effect, by command or button name: { bold: ["Mod+B"], ... }.

Icons, labels & theme

MemberDescription
setIcons(map)Override icons for this editor; null restores one. See Icons.
setLabels(map)Override labels for this editor; null restores one. See Labels & translation.
setTheme(tokens)Set --ve-* tokens on this editor, e.g. { accent: "#e11d48" }; null removes one. See Styling.
theme"light", "dark" or "auto" (follow the page). Reflects the theme attribute.

Events

All events bubble, so you can listen on the editor or on any ancestor (a form, the document).

Event list

EventWhen
inputThe content changed.
changeThe editor lost focus.
ve:update / editorupdateContent or selection state changed. Same event under two names (the second is easier to use in attribute-based frameworks).

Event detail

ve:update carries the full editor state in event.detail:

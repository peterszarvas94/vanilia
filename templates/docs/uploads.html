Images come in three ways: pasted, dropped onto the editor, or picked with the image button.

Without a server

With no setup, images are inlined as data: URLs in the HTML. That's fine for demos and small images; for anything else, store them on your server.

Upload URL

Set upload-url. Each image is POSTed as the raw file with its Content-Type; respond with the image's URL as JSON:

{{template "code" ` `}}

Upload function

For anything else (form data, signed URLs, a storage SDK), assign an async function that returns the URL:

{{template "code" `editor.onImageUpload = async (file) => { const body = new FormData(); body.append("file", file); const res = await fetch("/my/upload", { method: "POST", body }); return (await res.json()).url; };`}}

It takes precedence over upload-url. While it runs, the footer shows the uploading label; if it throws, the error message.

Editing images

Click an inserted image to resize it with the handles, pick a preset width, align it, edit its alt text or delete it.

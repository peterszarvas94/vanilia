All styles live in the cascade layers ve-tokens, ve-base, ve-chrome, ve-surface, ve-popovers, so any unlayered CSS of yours wins. Most of the time you only set variables, globally or per editor:

{{template "code" `vanilia-editor { --ve-accent: #e11d48; /* hover, focus ring and active states derive from it */ --ve-radius: 8px; --ve-min-height: 220px; --ve-max-height: 520px; /* scroll inside the editor beyond this */ --ve-font-sans: Inter, system-ui, sans-serif; }`}}

The soft, ring, border and hover accents are derived from --ve-accent (and the soft danger from --ve-danger) unless you set them.

Dark mode

Colors use light-dark(), so the editor follows the page's color-scheme. To pin one editor, set theme:

{{template "code" ` `}}

To use different colors per scheme, set your own tokens with light-dark():

{{template "code" `vanilia-editor { --ve-bg: light-dark(#fffaf3, #1c1712); --ve-border: light-dark(#e6d6bf, #3a2f24); }`}}

From JavaScript

setTheme() writes the same variables with typed, camelCase names (accentSoft is --ve-accent-soft). Use it when colors come from data, like a user's brand color. null removes a value.

{{template "code" `import { setTheme } from "vanilia-editor"; // every editor: an unlayered :root rule setTheme({ accent: "#e11d48", radius: "8px", fontSans: "Inter, sans-serif" }); // one editor: inline --ve-* properties on the element editor.setTheme({ accent: user.brandColor, minHeight: "120px" }); editor.setTheme({ accent: null }); editor.theme = "dark"; // same as the attribute`}}

Token names are exported as THEME_TOKENS and tokenVar(name) gives the CSS property. Precedence, lowest first: built-in defaults, setTheme() and your :root CSS, CSS on vanilia-editor selectors, editor.setTheme().

Classes you can style

The editor renders into the light DOM, so its parts are plain elements. These classes are stable across minor versions; others are internal.

SelectorElement
.ve-rootThe frame around everything. .is-disabled while disabled.
.ve-toolbarThe toolbar.
.ve-btn-group, .ve-sepA group of buttons and the separator between groups.
.ve-btnAny button. [data-cmd="bold"] picks one; .is-active when pressed; .ve-btn--custom for custom buttons.
.ve-surfaceThe editable area. [data-empty] while empty.
.ve-footer, .ve-status, .ve-metricsThe footer, its status message and the word count.
.ve-bubble-menuThe selection menu.
.ve-popoverLink and image popovers and the image toolbar.
.ve-find-barFind & replace.
.ve-iconAn icon (.ve-icon--custom when replaced).
.ve-proseAdd it to any container that shows saved HTML, for the editor's typography and image alignment.

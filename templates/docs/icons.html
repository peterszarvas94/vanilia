{{define "doc/icons"}}

The built-in icons are inlined, Lucide-style SVGs, so there's no icon library to load. Resize them or change their stroke width with --ve-icon-size, --ve-icon-size-sm and --ve-icon-stroke, or replace any of them with your own markup (inline SVG, an icon-font <i>, an <img>, or a server-rendered component).

JavaScript setup

{{template "code" `import { setIcons, ICON_NAMES } from "vanilia-editor"; // every editor on the page (mounted editors update too) setIcons({ undo: "", redo: "" }); // one editor editor.setIcons({ italic: '' }); // a new name, for a custom button's icon: "sparkles" setIcons({ sparkles: "" });`}}

Lookup order: the editor's own icons, then setIcons(), then the built-in SVG.

Icon names

bold italic underline strike code paragraph h1 h2 h3 bulletList orderedList quote hr alignLeft alignCenter alignRight link unlink image clear undo redo search upload trash check x copy text moon sun. The list is exported as ICON_NAMES.

Most match their button. The exceptions: blockquote uses quote, clearFormatting uses clear and find uses search. See the icons example.

Forms

<vanilia-editor> is a form-associated custom element, so it behaves like a native field: no hidden input, no JavaScript to copy the value over.

Submitting

It submits its HTML under its name, in regular form posts, FormData and libraries that serialize forms (htmx, Datastar):

{{template "code" `
`}}

An empty editor submits an empty string, not <p><br></p>.

Validation

With required, an editor with no text and no image fails validation and blocks submission, with the browser's usual message. The standard members work too:

{{template "code" `editor.checkValidity(); // false while empty and required editor.reportValidity(); // shows the message editor.validity.valueMissing; editor.validationMessage; // the "valueMissing" label, translatable`}}

Disabled and reset

disabled, on the editor or a parent <fieldset>, makes it read-only and leaves it out of the submission. form.reset() restores the initial content.

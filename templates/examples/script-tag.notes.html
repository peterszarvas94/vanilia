• vanilia-editor.iife.js is the classic-script build. It registers <vanilia-editor> and puts every export on window.Vanilia.
  • With defer (usually in the <head>), the script runs once the page has been parsed; put code that uses the editor in a DOMContentLoaded listener. Without defer it works too, but editors start only when parsing finishes, so the listener is still the place for your code.
  • Load either this file or the ES module on a page, not both: each has its own settings, so Vanilia.setLabels() only reaches editors created by the same build.

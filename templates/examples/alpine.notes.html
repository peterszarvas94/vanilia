• x-model works in both directions: Alpine reads the editor's value on every input event, and setting the model writes value, which replaces the content.
  • @editorupdate fires on every change and selection move. Its detail has html, text, words, images, active (formatting at the cursor), canUndo and canRedo.
  • No server needed. To save, put the editor in a <form> with a name, or send html with fetch.

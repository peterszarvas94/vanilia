• Uses React 19's native custom-element support: value is assigned as a property, oninput synchronizes React state, and oneditorupdate reads the word count. No wrapper package is needed.
  • Keep the editor empty in React's element tree. Vanilia owns the toolbar and editable DOM; React controls only the value property. The editor skips identical writes to preserve the caret.
  • The demo is written in demos/react.tsx, compiled at build time and shown verbatim in the Code tab. Its JSX declaration types the editor value and native events without any. Import the editor on the client before mounting the component.
  • The website self-hosts pinned React and React DOM bundles through its import map. See React's custom HTML element documentation.

• data-bind:body works because the editor behaves like a native field: it has a value property and fires input. Leave body out of data-signals so the signal starts from the editor's content instead of overwriting it.
  • @post sends every signal as JSON. The Go handler reads body with datastar.ReadSignals, sanitizes it and answers with SSE events: one patches #datastar-output, one sets $savedAt.
  • The editor marks its internals with data-ignore, so Datastar never walks or morphs them. Patch the elements around the editor, not the editor itself.
  • For formatting state, use the editorupdate event: data-on:editorupdate="$bold = evt.detail.active.bold". The playground wires up all of it, including session storage and a live preview.

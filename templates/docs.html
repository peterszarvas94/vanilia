Documentation

Everything you need to use <vanilia-editor>. It's a small library, so this is a short page.

Installation

Vanilia ships as one ES module and one stylesheet:

FileSize (gzip)What
vanilia-editor.js~44 kBThe element and its extensions, with a pinned Squire 2.4.11 (MIT) built in. Readable, not minified.
vanilia-editor.d.tsTypeScript types (optional)
vanilia-editor.css~4 kBAll styles, in cascade layers

The files on this site are served with CORS headers, so you can link them directly:

Option B: copy them into your project

Download the files into your static folder (for example /static/vendor/) and use the same snippet with local paths:

{{template "code" `curl -LO https://vanilia.peterszarvas.hu/dist/vanilia-editor.js curl -LO https://vanilia.peterszarvas.hu/dist/vanilia-editor.css curl -LO https://vanilia.peterszarvas.hu/dist/vanilia-editor.d.ts # optional, for types`}}
The import map has to come before any module script that imports Vanilia. Put it once in your base layout.

Option C: with a bundler

The module has no imports of its own, so a bundler needs nothing extra: import the copied files, and keep vanilia-editor.d.ts next to the module for types.

{{template "code" `// main.ts import "./vendor/vanilia-editor.js"; import "./vendor/vanilia-editor.css"; const editor = document.querySelector("vanilia-editor"); // VaniliaEditorElement | null`}}

The element is a form-associated custom element. It submits its HTML under its name, supports required and disabled (also from a parent <fieldset disabled>), and restores its initial content on form reset.

TypeScript

Types ship next to the module as vanilia-editor.d.ts. Keep it beside vanilia-editor.js and a relative import is typed with no setup. When you import the bare "vanilia-editor" through an import map, tell TypeScript where the types are, because it doesn't read import maps:

{{template "code" `// tsconfig.json { "compilerOptions": { "paths": { "vanilia-editor": ["./static/vendor/vanilia-editor.d.ts"] } } }`}}

Importing the module also types the element and its events, so there is nothing to cast. Commands and icon names are checked too:

{{template "code" `import "vanilia-editor"; const editor = document.querySelector("vanilia-editor"); // VaniliaEditorElement | null editor?.addEventListener("editorupdate", (event) => { console.log(event.detail.words, event.detail.active.bold); }); editor?.exec("bold"); // "bolt" would be a type error`}}

Exported types include VaniliaEditorDetail, EditorCommand, IconName and UploadHandler.

Styling

All styles live in the cascade layers ve-tokens, ve-base, ve-chrome, ve-surface, ve-popovers, so any unlayered CSS of yours wins. Most of the time you only set variables, globally or per editor:

{{template "code" `vanilia-editor { --ve-accent: #e11d48; /* hover, focus ring and active states derive from it */ --ve-radius: 8px; --ve-min-height: 220px; --ve-max-height: 520px; /* scroll inside the editor beyond this */ --ve-font-sans: Inter, system-ui, sans-serif; }`}}

Sanitizing on the server

The editor sanitizes pasted HTML in the browser, but anything a client sends can be forged, so sanitize again on the server before storing or rendering it. Allow only what the editor produces. For Go, this is the bluemonday policy this site uses (full source):

{{template "code" (print `p := bluemonday.NewPolicy() p.AllowStandardURLs() p.AllowRelativeURLs(true) p.AllowElements("p", "div", "br", "hr", "h1", "h2", "h3", "h4", "h5", "h6", "blockquote", "pre", "code", "ul", "ol", "li", "b", "strong", "i", "em", "u", "s", "del", "sub", "sup", "mark", "span", "a", "img", "figure", "figcaption") p.AllowAttrs("href", "title").OnElements("a") p.AllowAttrs("src", "alt", "title").OnElements("img") p.AllowAttrs("class").Matching(regexp.MustCompile(` "`" `^align-(left|center|right|justify)$` "`" `)).Globally() // image size and alignment styles p.AllowStyles("width", "max-width", "height"). Matching(regexp.MustCompile(` "`" `^(auto|\d+(\.\d+)?(%|px))$` "`" `)).OnElements("img") p.AllowStyles("display").Matching(regexp.MustCompile(` "`" `^(block|inline-block)$` "`" `)).OnElements("img") p.AllowStyles("margin-left", "margin-right").Matching(regexp.MustCompile(` "`" `^(0(px)?|auto)$` "`" `)).OnElements("img") p.AllowStyles("text-align").Matching(regexp.MustCompile(` "`" `^(left|center|right|justify)$` "`" `)).Globally() clean := p.Sanitize(r.FormValue("body"))`)}}

Browser support

Vanilia targets current evergreen browsers: Chrome / Edge 123+, Firefox 128+ and Safari 18+. It relies on custom elements with ElementInternals, the Popover API, CSS nesting, light-dark() and relative colors. CSS anchor positioning and the Custom Highlight API are used when available, with fallbacks.

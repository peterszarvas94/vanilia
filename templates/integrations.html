Plain HTML forms

No library at all: name, required, FormData and reset work natively.

Go + Datastar playground

Session storage, sanitizing on save, an SSE-rendered preview and every editor state as a signal.

Using something else?

Anything that works with an <input> works with the editor. It gives you:

valueThe content as HTML. Read it, or set it to replace the content.
input, changeFired on every edit, and when the editor loses focus.
editorupdateFired on edits and selection changes; detail has the HTML, text, word count and active formats.
name, requiredForm association: submitted with its form and validated like a native field.

See the API and events for the details.
